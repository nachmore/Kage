Why Kage

Out of sight until you call it.

影 (kage) is Japanese for "shadow". One keystroke and it's there, over whatever you're doing.

Fast first

Apps, math, timers and folders answer as you type, on your machine. None of it goes to the AI.

Your agent, not ours

No bundled model and no account. Kiro CLI, Claude Code, OpenAI Codex, a local Ollama model, or any ACP agent.

Nothing hidden

Every file read, edit, search and shell command appears under the reply, with its output. New tools need your OK.

Yours to shape

Sandboxed extensions, themes, your own commands and automations, 32 languages, and a cat that reacts to what's going on.

A launcher first, AI second

Answers before you finish typing.

What you type is matched on your machine first. Only text that matches nothing goes to your agent.

Apps by a few letters

Kage learns which result you pick and sees new installs right away.

Instant answers

Math and units, timers, UUIDs, hashes, base64, epoch times, JSON and colors.

Folders, files, system

down opens Downloads, *.pdf finds files, and lock, sleep or terminal do what they say.

Then, the AI

Enter on text that matches nothing asks your agent. Ctrl+Enter always does.

Chat, with every step in view

See exactly what your agent did.

  • Tool chips

    Under each reply, chips group what the agent read, edited, searched, fetched or ran. Expand one for diffs, arguments, results and errors.

  • Shell commands, in full

    The exact command, live status, exit code, stdout and stderr, with copy buttons.

  • Rich replies

    Highlighted code, math, Mermaid and Graphviz diagrams, sortable tables, and HTML previews in a sandbox.

  • Room to work

    Sessions to search, rename and export, a context-usage ring, a model picker, attachments, and plans you review before multi-step jobs run.

You decide what the agent runs

Nothing runs without your say-so.

The agent has to ask before it uses a tool you haven't allowed.

  • Allow or deny, your way

    Allow once, for 24 hours or always, or deny once or always. An unused "always" expires after 30 days.

  • Trust, with guard rails

    Trust all commands, or all tools from one MCP server, after a confirmation. Always deny still wins, and background features always ask.

  • A full audit trail

    Settings → Agent Permissions lists every tool and trusted server, with a local audit log and a reset button.

Terminator Mode approves everything you haven't set to Always deny, until you switch it off. A banner reminds you while it's on, and the cat dresses for the part.

And a lot more

Power tools, when you want them.

Commands & Prompts

Trigger words that open a program or URL, send a prompt with {selection}, or run a script.

yt cats→ searches YouTube for cats

Automations

Chains of prompts, find & replace, text transforms, conditions and scripts. Run by hand, on a schedule, or when a meeting is about to start.

Computer control

An optional MCP server that lets your agent launch apps, read and click their interface, type, and tidy folders.

Voice

A microphone button for speaking your prompt, and replies read aloud with system voices or the local Pocket TTS engine.

Backup & restore

Settings, prompts and extension data in one .kage file, optionally protected with a passphrase.

Stays out of the way

Lives in the tray or menu bar, runs as a single instance, can start at login, and can keep itself up to date with signed builds.

Untrusted by default

Every extension runs in a sandbox.

That includes the ones setup installs. Kage checks every request an extension makes (clipboard, files, windows, calendar, the agent…) against the access it declared. You see that list before you install, and again if an update asks for more.

Extensions marked Online talk to a web service: Dictionary, for example, looks up the words you type.

Privacy and security

Private by design. Honest about the details.

No Kage account, no Kage cloud

Your prompts go to the agent you connect, and from there to whichever model service it uses, or nowhere else with a local Ollama model.

You approve the tools

The agent asks before it uses a tool you haven't allowed, and every command it runs shows up under the reply.

Sandboxed extensions

Every extension is untrusted. Each request it makes is checked against the access it declared.

Signed updates

Every download is verified against a signing key built into the app before it's installed.

Analytics you can switch off

Anonymous usage events never include your messages, prompts, replies, file names or paths. Setup explains them with a switch that starts on; turn it off there or in Settings → Privacy.

Screen context, disclosed

By default, prompts include the name and window title of the app you came from. Turn it off in Settings → System Integration.

Read the privacy policy, the security model and how tool permissions work.

Download

Get Kage.

Kage is under active development and publishes Nightly builds for now.

Windows

Windows 10 or 11, x64

Download for Windows

Kage_<version>_x64-setup.exe

Installs for your user only, so no admin rights. The builds aren't code-signed yet, so SmartScreen may say "Windows protected your PC": choose More info → Run anyway.

On Windows 10, the installer adds Microsoft's WebView2 runtime if it isn't there yet.

macOS

macOS 11 or later, Apple Silicon

Download for macOS

Kage_<version>_aarch64.dmg

The Mac builds aren't signed or notarized yet. Before you open the DMG, remove the quarantine flag in Terminal:

xattr -d com.apple.quarantine ~/Downloads/Kage_*_aarch64.dmg

Then open the DMG and drag Kage to Applications. Intel Macs aren't supported. Already seeing "damaged"? See the install guide.
